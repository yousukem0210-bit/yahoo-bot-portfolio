# 中古PC自動検索・AI評価Bot

## 制作概要
中古ノートPC探しを効率化するため、商品検索・条件判定・AI評価・通知までを自動化するBotを制作しました。

## 主な機能
- Yahoo!オークションから商品を自動検索
- CPU・メモリ・SSD・価格などを自動判定
- Pythonによる100点満点のスコアリング
- OpenAI APIによる商品情報・画像の評価
- 「買い候補・要確認・見送り」の判定
- Discordへの自動通知
- GitHub Actionsによる定期実行

## 使用技術
Python / OpenAI API / GitHub Actions / Discord Webhook / Beautiful Soup

## 工夫した点
すべての商品をAIで評価するのではなく、Pythonで候補を絞り込んでからAI分析することで、API利用コストを抑えています。
